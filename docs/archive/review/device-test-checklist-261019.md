## 3. P0（必测，任一失败即挡发布）

1. ⚠️ **密码登录（API 19–32）** — 本批唯一的「线上静默失败」根因修复（`PasswordEncryptUtil` 用了 API 33 才有的 `strip()`，API≤32 上直接抛异常被吞 → 一直登不上）。
   - 步骤：退出登录 → 账号密码登录（用一台 Android ≤12 的设备，或同时验证扫码）。
   - 预期：登录成功并回到「我的」；失败时提示是人话，不是空白。
   - 备注：模拟器是 Android 12（API 32），**这条其实我可以在模拟器补测**，但真机更可信；扫码登录不受此影响。
2. ⚠️ **下载完整链路**（`1df47b9`，改动 433 行）
   - a) 默认目录下载：视频详情 → 缓存 → 选清晰度 → 下完能播、弹幕/封面在。
   - b) `.bak` 恢复：下载到一半「暂停 → 杀进程 → 重进缓存页」→ 成品应被 `.bak` 恢复，列表里状态与文件相符。
   - c) 同名覆盖：再下一次同名视频 → **旧成品不能在中途断流时丢失**。
   - d) 失败分片回滚：断网下载 → 进度百分比不能虚高（不能显示 80% 但文件只有 10%）。
   - e) 覆盖安装升级（旧版本 → 本包）后进缓存页：下载记录不丢、不弹「数据库损坏」。
3. ⚠️ **POST 失败提示**（`NetWorkUtil.post` 非 2xx 现在会抛 `IOException`，不再把错误页当成功）
   - 步骤：断网/飞行模式下依次发：弹幕、评论、点赞、投币、收藏、「稍后再看」、发动态、私信发图。
   - 预期：每条都明确报错（toast/对话框），**不静默成功、不永久转圈、不崩**；恢复网络后重试成功。
4. ⚠️ **消息页失败复位**（`MessageActivity` 原先失败分支不复位，永久转圈）
   - 步骤：断网进消息页 → 等失败 → 恢复网络 → 下拉刷新（或切 tab 再回来）。
   - 预期：能恢复加载；不再一直转圈。
5. **播放三件套**：普通视频播放/拖动进度/切清晰度；短视频连播 10 条（`infbuf` 已删，关注卡顿/黑屏/内存）；直播间进出 + 卡顿重连（`reconnect_at_eof` 只对直播加，**点播播完不能自己重播**）。
6. 🕐 **表冠**（手表）：a) 设置里打开「启用表冠适配」后，推荐/热门/消息/关于等**无输入框的页面**都能滚；b) 改灵敏度（1.0 → 0.25）**不重进页面**立刻生效；c) 关开关后完全不响应；d) 教程弹窗/横向翻页页只滚当前页、不误翻页；e) 长文页（简介/评论）能一直滚到底。

## 7. 手机/系统版本专属

- **API 19–32**：重点就是第 1 条（密码登录）与存储权限降级；`minSdk 19` 注释已统一，但 `WRITE_EXTERNAL_STORAGE` 在 Android 13+ 已失效——13/14 上必须走「所有文件访问」二级降级，别只在 12 上测。
- **Android 13+ 通知权限**：消息页申请 `POST_NOTIFICATIONS`，拒绝后通知静默（属预期）。
